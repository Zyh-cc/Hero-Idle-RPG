# 出行推荐 App — 设计文档

**日期：** 2026-03-29
**形式：** 单文件网页 Demo（个人工具）
**目标用户：** 个人使用，验证核心想法

---

## 1. 产品概述

根据用户当前位置、实时天气和出行意图，通过 AI 从高德 POI 数据中筛选并推荐附近目的地，每个推荐附带"为什么今天适合去"的 AI 生成理由。

**示例场景：** 南京江宁用户，今天晴天22°C，选择"开车 + 自然风景"，输入"想随便转转"，系统推荐牛首山、将军山、方山等并说明理由。

## 2. 技术架构

### 2.1 整体结构

单个 HTML 文件，无后端，浏览器直接打开即用。

### 2.2 数据流

```
用户操作
  → [1] 位置获取：浏览器 Geolocation API（GPS）或手动输入城市名
              （手动输入时调用高德地理编码 API 将城市名转为经纬度）
  → [2] 天气获取：和风天气 API（实时）或手动选择（晴/多云/雨/雪）
  → [3] 用户意图：交通标签 + 活动类型标签（可多选）+ 可选自由文本
  → [4] POI 搜索：高德地图 REST API，以经纬度为中心做周边搜索
              （根据活动标签映射搜索类型，如"风景名胜|公园|景点"）
  → [5] AI 推荐：将天气 + 用户意图 + POI 列表组装为 Prompt，
              发送给选定 AI 模型，返回带排序和推荐理由的 JSON
  → [6] 渲染结果：卡片列表展示推荐地点
```

### 2.3 所需 API

| API | 用途 | 免费额度 |
|-----|------|---------|
| 高德地图 Web API | POI 周边搜索 | 每日 5000 次 |
| 和风天气 API | 实时天气数据 | 每日 1000 次 |
| AI 模型 API（可选） | 推荐理由生成 | 见下方 |

**支持的 AI 提供商（设置面板可切换）：**

| 提供商 | 推荐模型 | 费用 | 备注 |
|--------|---------|------|------|
| DeepSeek（默认） | deepseek-chat | 极低 | 国内直连，中文效果好 |
| Anthropic | claude-haiku-4-5 | 极低 | 需科学上网 |
| 阿里通义千问 | qwen-turbo | 有免费额度 | 国内直连 |
| Google Gemini | gemini-flash | 有免费额度 | 需科学上网 |

### 2.4 Key 存储

所有 API Key 存入浏览器 `localStorage`，首次打开自动弹出设置面板引导填写，后续自动读取。

## 3. 界面设计

### 3.1 三步流程布局

页面分为三列（或移动端竖向堆叠）：

**第 1 步 — 位置 & 天气**
- 自动定位按钮（调用 Geolocation API）
- 手动输入城市名备选
- 天气自动获取展示（图标 + 温度 + 湿度 + 风力）
- 支持手动覆盖天气

**第 2 步 — 出行想法**
- 出行方式标签（单选）：🚗 开车 / 🚶 步行 / 🚌 公交 / 🚲 骑行
- 活动类型标签（多选）：🌿 自然风景 / 🏛 历史文化 / 🍜 美食 / 🛍 购物 / ☕ 休闲
- 可选自由文本输入（补充说明）
- "✨ 获取 AI 推荐"按钮

**第 3 步 — 推荐结果**
- 卡片列表，每张卡片包含：
  - 地点名称
  - 距离（km）
  - 类别标签
  - AI 生成的推荐理由（结合当天天气和用户意图）

### 3.2 设置面板

顶部导航栏入口，包含：
- AI 提供商选择（下拉）
- AI API Key 输入
- 高德地图 API Key 输入
- 和风天气 API Key 输入
- 搜索半径设置（默认 20km，可调）

## 4. AI Prompt 设计

```
你是一个出行推荐助手。根据以下信息，从候选地点列表中挑选最合适的3-5个，
并为每个生成一句推荐理由（30字以内，结合天气和用户意图）。

当前信息：
- 位置：{city}
- 天气：{weather_desc}，{temp}°C，{wind_desc}
- 出行方式：{transport}
- 活动偏好：{activities}
- 补充说明：{user_text}

候选地点（高德POI搜索结果，格式：序号. 名称 | 类别 | 距离km）：
{poi_list}

请返回 JSON 格式：
[{"name": "地点名", "reason": "推荐理由", "rank": 1}, ...]
```

## 5. 错误处理与降级

| 场景 | 处理方式 |
|------|---------|
| GPS 定位失败 / 拒绝授权 | 自动切换到手动输入城市名 |
| 天气 API 失败 | 弹出手动天气选择器，不阻断主流程 |
| 高德 POI 无结果 | 提示"附近未找到相关地点"，提供"扩大至 50km"按钮 |
| AI API 失败 / 超时 | 降级展示 POI 列表（无推荐理由），卡片标注"AI 推荐暂不可用" |
| API Key 未填写 | 首次打开自动弹出设置面板 |
